# claude-brainrot

Claude drops memes (image + sound) into your Claude Code chat. Autonomously. With brainrot energy.

## Install

```bash
npx skills add marks97/claude-brainrot -a claude-code -g
```

## Requirements

- macOS, Linux, or WSL
- `bash` and `jq`
- A sound player (auto-detected): `afplay` on macOS, or one of `paplay` / `ffplay` / `mpg123` / `mplayer` on Linux

That's it.
